# MaxVaultApp — WinForms приложение «Пароли»

Готовый проект на **C# WinForms** для варианта 8 — локальный менеджер паролей с современным тёмным интерфейсом.

## Что реализовано

- локальное хранение данных без интернета;
- мастер-пароль при первом запуске;
- шифрование хранилища через **AES-GCM**;
- добавление, редактирование и удаление записей;
- поля записи:
  - название сервиса;
  - логин;
  - пароль;
  - категория;
  - дата создания;
  - дата последней смены;
  - заметки;
  - пометка "важное";
- поиск по названию, логину и заметкам;
- фильтр по категории;
- вкладка избранных паролей;
- статистика по категориям;
- предупреждения:
  - пароль не менялся более 6 месяцев;
  - одинаковый пароль используется в нескольких сервисах;
- генератор паролей:
  - буквы;
  - цифры;
  - символы;
  - длина от 8 до 20;
- проверка силы пароля;
- предложение сгенерировать новый при слабом пароле;
- экспорт резервной копии в **зашифрованный backup** (`.bak`);
- импорт резервной копии.

## Стек

- .NET 8
- Windows Forms
- System.Text.Json
- System.Security.Cryptography

## Как собрать

1. Откройте `MaxVaultApp.sln` в **Visual Studio 2022** или новее.
2. Убедитесь, что установлен workload **.NET Desktop Development**.
3. Выберите конфигурацию `Release`.
4. Нажмите **Build -> Build Solution**.
5. Запустите проект.

## Где хранятся данные

После запуска приложение создаёт локальную папку:

`%LocalAppData%\MaxVaultApp`

В ней будут:

- `vault.dat` — зашифрованное основное хранилище;
- `Backups\` — резервные копии.

## Важные замечания

- приложение не использует интернет;
- без мастер-пароля хранилище не открыть;
- резервная копия экспортируется в уже зашифрованном виде;
- проект подготовлен как полноценный учебный/курсовой вариант с красивым UI и логикой безопасности.
